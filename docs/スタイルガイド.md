# プロンプトインジェクション検査サイト スタイルガイド

Tailwind CSS に関するプロジェクト共通のスタイルルール。

## 1. ビューポート高さ: `dvh` を使う

### ルール

- `h-screen` / `min-h-screen` は**使用禁止**
- 代わりに `h-dvh` / `min-h-dvh` を使用する
- `calc()` 内の `100vh` も `100dvh` に置き換える

### 理由

モバイルブラウザ（iOS Safari, Android Chrome 等）では、アドレスバーやナビゲーションバーの表示/非表示により `100vh` が実際の可視領域と一致しない。`dvh`（Dynamic Viewport Height）を使うことで、ブラウザ UI の状態に応じた正確な高さを取得できる。検査ページは入力エリアと結果エリアを縦に並べるため、モバイルでの高さ計算が重要になる。

### ビューポート単位の比較

| CSS 単位 | Tailwind クラス | 説明 |
|----------|----------------|------|
| `100vh` | `h-screen` | ブラウザ UI を含む固定サイズ。モバイルで問題になりやすい |
| `100dvh` | `h-dvh` | ブラウザ UI の表示/非表示に応じて動的に変化（推奨） |
| `100svh` | `h-svh` | ブラウザ UI が表示された状態の最小ビューポート |
| `100lvh` | `h-lvh` | ブラウザ UI が非表示の状態の最大ビューポート |

### 具体例

```tsx
// NG
<div className="min-h-screen bg-gray-50">
<div className="h-screen md:h-[calc(100vh-96px)]">

// OK
<div className="min-h-dvh bg-gray-50">
<div className="h-dvh md:h-[calc(100dvh-96px)]">
```

### ブラウザサポート / 備考

`dvh` は主要ブラウザで広くサポート済み（Chrome 108+, Safari 15.4+, Firefox 101+）。古い環境への対応が必要な場合のみフォールバックを検討する。

## 2. カラーパレット構成

### ルール
- リスクレベルや Primary 等の色は、テーマトークン（`bg-primary` / `text-destructive` 系）を使用する
- 直に `#hex` 値を `className="text-[#333]"` のように指定しないこと

### 理由
ダークモード対応やテーマ変更時の保守性を高めるため。特にリスクレベルの色（安全／注意／危険）はセマンティックトークンに寄せることで、一貫した配色を保てる。

### 具体例
```tsx
// NG
<span className="bg-[#dc2626]">危険</span>

// OK
<span className="bg-destructive text-destructive-foreground">危険</span>
```

## 3. リスクレベルの表現（色のみに依存しない）

### ルール
- リスクレベル（安全／注意／危険）は**色だけで区別しない**。ラベル文言またはアイコンを必ず併記する
- 十分なコントラスト比（WCAG AA: テキスト 4.5:1 以上）を確保する

### 理由
色覚特性のあるユーザーやスクリーンリーダー利用者にも、リスクの高低が正しく伝わるようにするため（アクセシビリティ要件）。

### 具体例
```tsx
// NG（色のみ）
<div className="text-destructive">●</div>

// OK（ラベル + アイコン + 色）
<div className="flex items-center gap-1 text-destructive">
  <AlertTriangle aria-hidden /> <span>危険</span>
</div>
```

## 4. 不可視文字・コードの表示

### ルール
- 検出した不可視文字（ゼロ幅・制御文字）は生のまま表示せず、`⟨ZWSP⟩` のような**可視ラベル**に置換して表示する
- 検出されたマッチ文字列やコード片は `font-mono` 等の等幅フォントで表示し、通常テキストと区別する

### 理由
不可視文字はそのまま描画すると存在が分からないため、可視化して初めて「隠された指示」の危険性が伝わる。等幅表示は記号・区切りマーカーの視認性を高める。
