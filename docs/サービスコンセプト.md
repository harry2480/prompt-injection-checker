# プロンプトインジェクション検査サイト - サービスドキュメント

## サービス概要

本サービスは、任意のテキスト（プロンプト・ドキュメント・外部から取得したコンテンツ等）に**プロンプトインジェクションが含まれていないか**を、ブラウザ上で誰でも無料・登録不要で検査できるプラットフォームです。ルールベースの検知エンジンをクライアントサイド（ブラウザ内）で実行することで、入力内容を外部に送信せずに、代表的なインジェクション手口を**可視化**します。GitHub Pages 上の静的サイトとして提供し、低コスト・高可用に運用します。

## コンセプト

### 1. プライバシーファーストな一次スクリーニング

**目的**: LLM に渡す前のテキストを、安全な環境で素早くチェックできるようにする

**機能**:
- 入力テキストをブラウザ内だけで解析（外部送信なし・オフライン動作）
- 命令上書き・役割変更・機密抽出・不可視文字等のカテゴリ別検知
- リスクレベル（安全／注意／危険）とスコアの提示

### 2. 検出根拠の可視化と学習支援

**目的**: 「なぜ危険なのか」を提示し、利用者が自分で判断・学習できるようにする

**特徴**:
- マッチした箇所をテキスト上でハイライト表示
- カテゴリ別サマリーと各検出の説明・根拠を提示
- 検知ルールカタログ（手口の解説）でセキュリティ学習にも活用可能

**参考事例**: 各種プロンプトインジェクション辞書・OWASP LLM Top 10（LLM01: Prompt Injection）

### 3. 静的・軽量・拡張可能なアーキテクチャ

**目的**: サーバーレスで低コスト運用しつつ、将来の高精度化に拡張できる基盤を持つ

**主要機能**:
- **ルールベース検知エンジン**
  - 正規表現・辞書・Unicode/構造解析による多カテゴリ検知
  - ルールをデータとして分離し、追加・保守を容易化
- **複数入力ソース対応**
  - テキスト貼り付け／ファイル読込／URL取得
- **将来拡張（ロードマップ）**
  - BYOK による LLM 判定、ブラウザ内ローカルモデル、ブラウザ拡張化

### 4. 検知精度の継続的改善

**目的**: 手口の進化に追随し、誤検知・見逃しを抑える

**対象と機能**:
- **検知ルール辞書**
  - 日英・言語非依存ルールの継続的な追加・更新
  - サンプル集を用いた回帰テスト（Unit テスト）
- **検出結果の透明性**
  - 一次スクリーニングであり結果を保証しない旨を常時明示

## 期待される効果

1. **安全性の向上** - LLM アプリに悪意ある指示が混入するリスクを事前に低減
2. **プライバシー保護** - 機微なテキストを外部に出さずに検査可能
3. **学習効果** - どんな手口が存在するかを検査を通じて理解できる
4. **低コスト運用** - 静的ホスティングによりサーバー費用ゼロで高可用

## 技術スタック（想定）

- フロントエンド: Next.js 15 (App Router) 静的エクスポート + TypeScript
- 検知ロジック: 純粋な TypeScript 関数（ドメイン層、外部依存なし）
- UI: shadcn/ui + Tailwind CSS
- バックエンド: なし（サーバーレス・静的サイト）
- インフラ/ホスティング: GitHub Pages（GitHub Actions でデプロイ）
- 外部連携/AI: 初期はなし（将来 BYOK による LLM 連携を検討）
- 認証: なし
